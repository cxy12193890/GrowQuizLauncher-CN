📖 AI 批量生成题库教程

1
把提示词发给 AI 复制下方模板，把「7 岁」「20 道」「数学口算」换成你需要的年龄、数量和主题，发给任意 AI 助手（如腾讯元宝、豆包、DeepSeek、ChatGPT 等）。 
你是一位小学教育专家。请为 7 岁儿童编写 20 道四选一选择题，主题是「数学口算」。

要求：
1. 题目难度符合该年龄的认知水平，表述口语化、无歧义；
2. 每题恰好 4 个选项，选项互不相同，只有 1 个正确答案；
3. 干扰项要有迷惑性，但能明确区分对错；
4. 答案在 4 个选项中的位置尽量随机分布，不要固定在某一项；
5. explanation 用一句话向孩子讲清为什么；
6. 只输出 JSON 数组，不要输出任何其他文字。每道题的格式如下：

[
  {
    "age": 7,
    "category": "数学",
    "question": "小明有 3 个苹果，吃了 1 个，还剩几个？",
    "options": ["1 个", "2 个", "3 个", "4 个"],
    "answerIndex": 1,
    "explanation": "3 - 1 = 2，所以还剩 2 个。"
  }
]

其中 answerIndex 是正确选项在 options 中的下标（0 表示第一个选项）。
2
把 AI 的输出保存为 .json 文件 AI 回复的 JSON 数组原样复制，用记事本等工具保存为 UTF-8 编码的 .json 文件（例如「一年级数学.json」）。如果 AI 一次给的题不够，可以让它「按同样格式再出 20 道」，把几段数组合并成一个。
3
在本页底部上传文件 选择导入方式后上传。系统会逐题校验，全部合格才会入库；不合格的题会按行号列出原因，改好后重新上传即可。

📐 文件格式要求

文件内容是一个 JSON 数组，数组里每个对象是一道题。字段如下：

字段类型要求
age整数适合年龄，5–15
category文本题目分类，如「数学」「识字」「安全常识」，导入后按分类筛选
question文本题干，不能为空
options数组恰好 4 个互不相同的选项
grade可选整数1–9 对应年级，10 为幼儿园大班，0 或省略表示未分类。
term可选整数1 上册，2 下册，0 或省略表示未标注。选择上下册时需填写 grade。
difficulty可选整数1–5 依次为入门、基础、中等、提高、挑战，0 或省略表示未分类。
answerIndex整数正确选项的下标，0–3（0 代表第一个选项）
explanation文本可选，答对后显示给宝贝的解析

完整示例（两道题）

[
  {
    "age": 7,
    "category": "数学",
    "question": "小明有 3 个苹果，吃了 1 个，还剩几个？",
    "options": ["1 个", "2 个", "3 个", "4 个"],
    "answerIndex": 1,
    "explanation": "3 - 1 = 2，所以还剩 2 个。"
  },
  {
    "age": 8,
    "category": "安全常识",
    "question": "陌生人敲门时，小朋友应该怎么做？",
    "options": ["马上开门", "先问清楚再告诉大人", "大声哭", "从窗户爬出去"],
    "answerIndex": 1,
    "explanation": "不能给陌生人开门，要先告诉家里的大人。"
  }
]
  • 单文件不超过 8 MB，一次最多导入 5000 题，超出请拆分文件。
  • 同年龄、同分类、同题干的题视为重复，导入时自动跳过。
  • 任何一道题不合格，整批都不会导入，并会列出每道错题的行号和原因。
  • 导入的题属于「自定义」分类，可在题库管理页编辑、禁用或删除。
