# TVQuizLock 素材与第三方授权核查

最后核查日期：2026-11-10

**发行结论：暂不允许发布收费正式版。** 代码可以继续编译和内部测试，但在下列阻断项取得书面授权或替换为可证明有权使用的素材前，不得创建正式 Release。

## 1. 上游代码

| 素材 | 已核实信息 | 结论 |
|---|---|---|
| Plume Launcher 桌面代码 | 本仓库保留 GPL-3.0 LICENSE 和上游来源说明；本项目是其二次开发 | 可按 GPL-3.0 条件使用、修改和分发；必须保留许可与版权声明，并向接收者提供对应完整源码 |
| Aerial Views 场景列表/相关代码 | 上游文档标注来源项目 Aerial Views，代码许可 GPL-3.0 | 按 GPL-3.0 保留来源和许可；不因此取得 Apple/Amazon 视频内容的版权 |

## 2. 字体与图标

| 素材 | 核查结果 | 处理 |
|---|---|---|
| Fraunces 字体 | 已从商业分支移除未核实的二进制，应用改用 Android 系统衬线字体 | 不再分发该字体二进制 |
| Material Symbols | 上游项目说明标注 Google Material Symbols，Apache-2.0；Google 官方指南确认该许可 | 已将 Apache-2.0 文本放入 `LICENSES/Apache-2.0.txt`，并在第三方声明中注明来源 |
| Simple Icons | 上游项目说明标注 CC0 | 保留来源说明；如具体图标文件并非来自所声明版本，需重新核对 |

## 3. 阻断商业发行的素材

### 题库（33,000 条）

检查了 `tools/generate_questions.py`、`tools/question_data/*.py` 和内置 JSON 分片。仓库中没有找到完整的题目来源清单、作者声明、授权协议或采购凭证。代码存在不等于题目数据的商业版权已获许可。

**需要：** 提供每个题库来源及可商用授权证明；或者用拥有完整著作权的原创题目替换。未完成前不得收费发行。

### 4K 壁纸包及内置壁纸

**已处理：** 商业分支已删除 10 张无授权凭证的 4K 壁纸和 APK 内的 Arctic Aurora 图片；壁纸包下载入口已移除，旧版本保存的 pack/Bing 壁纸会迁移为纯色背景。应用仅保留用户自己选择或上传的图片/视频，以及设备本地应用海报。

**后续要求：** 如要重新加入内置壁纸，必须先提交创作者、原始来源、商业使用和再分发授权证明。

### 题库质量复核（非版权结论）

APK 静态检查记录：33,000 条题目记录中有 7,187 条跨年龄段重复题干；其中 80 组的题干、选项和答案完全相同。重复题干不一定都是错误，因为不同年龄可能需要复习同一知识点；但完全相同的题目应在年龄梯度复核后去重或替换。

**当前状态：未修改题库内容。** 题目来源及著作权仍未核实，先保留原始题目 ID 与记录，避免在来源核验前破坏题库追溯关系。收费发行前必须完成重复题目复核，并保留变更记录。

## 4. 在线视频与外部内容

**已处理：** 商业分支的内置 NASA、Apple Aerial、Amazon Fire TV 场景目录已禁用，Aerial 场景选择入口已从家长界面移除；未经核实的 Gallery 画作下载也已移除。Bing 每日壁纸下载器和入口已删除。家长仍可上传自己拥有或获准使用的照片、视频。

**后续要求：** 如要重新开放任何第三方在线内容，必须逐项审核来源条款、商业展示权、下载/缓存权及再分发权，并记录具体 URL 与署名要求。
