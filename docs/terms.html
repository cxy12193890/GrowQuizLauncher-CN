电视答题锁使用条款

更新日期：2026年11月10日

一、软件性质

电视答题锁是一款面向 Android TV 的儿童定时答题与家长管理工具。不同电视品牌、Android 版本和厂商固件对主屏幕、无障碍服务、精确闹钟及后台启动的限制不同，因此部分功能可能因设备而异。

三、设备权限与内容

部分功能需要用户授予安装未知应用、显示在其他应用上层、精确闹钟、无障碍服务或设备所有者等权限。请先阅读电视系统提示，再决定是否开启。家长应自行判断题目内容是否适合儿童的年龄和学习阶段。

应用通过本项目 GitHub Releases 检查更新。更新下载需要设备能够访问 GitHub。天气、壁纸、屏保和其他外部内容由相应第三方服务提供，可能受其服务可用性、地区限制和使用条款影响。
