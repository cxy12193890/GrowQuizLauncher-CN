电视答题锁隐私政策

更新日期：2026年11月10日

电视答题锁（以下简称“本应用”）运行于 Android TV。我们尽量让学习记录和家长设置保留在电视本机。

一、我们不会做什么

  • 不要求注册账号，不投放应用内广告。
  • 不把电视型号、设备指纹、已安装应用列表、答题记录、崩溃堆栈或本地诊断日志上传给开发者服务器。
  • 不通过远程诊断接口收集设备兼容性报告。自动诊断上报功能已从本版本移除。

二、保存在电视本机的信息

  • 家长设置、管理密码的哈希值、答题年龄与间隔、题目开关、自定义题目和学习统计保存在电视应用私有存储中。
  • 崩溃记录与运行诊断事件只保存在电视本机，用于本机故障提示和家长管理页面查看。
  • 家长管理页面由电视在本地网络提供。手机与电视连接同一 Wi-Fi 后，手机浏览器直接访问电视的局域网地址；首次使用需要设置管理密码。该页面不经过开发者服务器。
  • 通过二维码向电视添加照片或视频时，手机与电视在同一局域网内直接传输，文件不会经由本应用的外部服务器中转。

三、应用会连接的外部服务

当设备连接互联网时，外部服务可能看到电视的 IP 地址、请求时间和常规网络请求信息：

  • GitHub：应用每天检查本项目的公开 Releases API；只有用户选择安装更新时，才下载本项目发布的 APK。
  • Bing：仅在用户选择“每日图片”壁纸时请求图片。
  • 天气服务：仅在用户开启天气功能时，可能通过 IP 定位服务估算大致位置，并向天气服务请求天气数据。
  • 壁纸和屏保内容源：仅在用户主动选择相应内容时，应用才会访问对应来源，例如 NASA、Apple 或 Amazon 的内容地址。相关内容由其来源方提供，适用其各自条款和隐私政策。

本应用不控制这些外部服务如何处理其收到的网络请求。关闭对应功能或不选择相关内容，可避免触发相应请求。

四、无障碍服务

本应用的无障碍服务用于响应电视遥控器按键、帮助主屏幕键返回本应用，以及执行用户设置的按键映射。它可能读取当前前台窗口所属应用信息以判断是否需要返回桌面，但不读取其他应用的屏幕文字、聊天内容或用户输入内容，也不会把这些信息发送到互联网。用户可以在 Android 无障碍设置中关闭该服务。

五、儿童信息

题目作答、答题成绩和家长自定义题目保存在电视本机。本应用没有儿童账号系统，也不向开发者服务器上传儿童学习记录。

六、政策变更与联系

如果隐私处理方式发生变化，我们会更新本页面。问题反馈请通过项目仓库提交：GitHub Issues。
