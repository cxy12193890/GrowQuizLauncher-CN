<h1 align="center">电视答题锁 · TVQuizLock Launcher</h1>

<p align="center"><em>一台会提问的电视桌面：到点自动出题，答对才回到动画片。</em></p>

---

## 这是什么

孩子看完一集还想再看一集，家长不可能每次都守在旁边。

**电视答题锁**把 Android TV 的桌面换成一个小而快的启动器，并按你设定的间隔把全屏答题弹到最前面：题答错了就换一道继续，答对了才回到桌面。题目全部离线内置，音量键、返回键都进不去动画片——想继续看，先答对一题。

它基于开源桌面 [Plume Launcher](https://github.com/aradhyas8/Plume_Launcher)（无广告、无账号、无统计的极简 TV 桌面，APK 约 0.4 MB），在保留原桌面全部功能的前提下加入儿童问答与家长管理模块；电视答题锁自身安装包约 1.0 MB。



## 核心功能

| | 功能 | 说明 |
|---|---|---|
| ⏱ | **定时全屏问答** | 到达设定间隔（1 分钟 – 24 小时）自动弹出问答，抢占前台并全屏显示 |
| 🔁 | **答错换题，答对返回** | 答案错误只换一道题，不提供"退出"；答对后自动返回桌面并重新计时 |
| 🧠 | **33000 道离线题库** | 5–15 岁十一个年龄段，每段 3000 题，涵盖数学、语文、科学、历史等 12 个分类，无需联网、无需登录 |
| 🗂 | **分类多选抽题** | 家长可按分类多选抽题范围（如只出数学和英语），不选即为全部；控制台按年龄显示各分类题量，该年龄无题的分类自动置灰不可选 |
| 📥 | **批量导入题库** | 控制台内置 AI 出题教程与提示词模板，AI 批量生成的题库文件（JSON）上传即入库，逐题校验、重复跳过，与内置题一起随机出现 |
| 🛠 | **题库维护** | 控制台可按年龄、分类、状态筛选题目，批量禁用/启用；同一道题答对满 5 次自动"退休"，不再出现 |
| 🔊 | **语音朗读题目** | 只对 10 岁及以下的题目朗读，11 岁起自己看屏幕。符号、括号、分数、单位都会转成可读字词；只有一个字/数字/字母（或一串英文）的选项不朗读——一读就等于送答案 |
| ⏳ | **答题先思考** | 出题后数秒内选项不生效，屏幕显示倒计时，杜绝秒选乱点；默认 5 秒，管理台可调 0–60 秒 |
| 😮‍💨 | **连续答错强制休息** | 连错 3 题休息 10 分钟，之后每多错一题多休息 10 分钟；重启也赖不掉；管理台可一键解除或整体关闭 |
| 🕵️ | **蒙题验证** | 快速连错后又快速答对，追加一道验证题；验证答错按连错 3 题处理，立即休息 |
| 🔁 | **切走后自动弹回** | 答题时切到别的应用（含遥控器上的一键直达键），一秒内自动回到题目，默认开启；控制台可开关，并显示它是否真的拦截过、最近一次是什么时候 |
| 🏆 | **成长等级体系** | 答对 +10、答错 −5、同题重复答错再额外 −8（答对该题即清零错题记忆）；塑料→铁→铜→白银→黄金→铂金→钻石，每级 4 阶共 28 阶，积分 4 万封顶钻石 4 阶；答题页顶部实时显示等级徽章与积分，升阶触发全屏庆祝动画与语音祝贺 |
| 📊 | **学习统计报告** | 控制台「报告」分页：按整体/年度/半年/季度/月度/周度查看答题量与正确率变化、知识点掌握分布、高频错题 TOP5、学习活跃天数与看电视时长（看电视统计依赖「主屏幕键」无障碍服务） |
| ⏻ | **开机先答一题** | 开机后弹出管理端提醒，按「确定」立即答一题。提醒每次开机只弹一次，点过「我知道了」当次开机不再弹（管理控制台可关闭，默认开启） |
| 🔒 | **设备所有者锁定** | 配置 Device Owner 后启用 Lock Task，答题期间无法用遥控器切走 |
| 🔑 | **设置密码保护** | 设置管理密码后，电视上的 Wi-Fi、系统设置和桌面设置入口也需输入密码 |
| 📱 | **手机当管理台** | 电视内置一个局域网网页控制台（默认 `:8081`），手机浏览器即可改年龄、间隔、管题库、立即出题 |
| ⬆️ | **自动更新** | 每天自动检查本项目 GitHub Releases；发现新版本后在设置中提示安装，APK 直接从本项目 Release 资产下载 |
| ♻️ | **开机自动恢复** | 重启电视后自动重新排定下一次问答，不必手动打开应用；答题或强制休息中途断电，开机后自动回到对应界面 |
| 🖥 | **完整桌面功能** | 应用行、继续观看、HDMI 信号源、壁纸/屏保、遥控器按键自定义等上游能力全部保留 |

## 快速开始

### 1. 获取 APK

**方式一：直接下载（推荐）**

从 [GitHub Releases](https://github.com/cxy12193890/GrowQuizLauncher-CN/releases) 下载最新版 `TVQuizLock-vX.Y.Z.apk`。正式版必须使用项目固定签名密钥；未配置密钥时只生成测试构建，不作为正式发行包。新包名为 `com.tvquizlock.app`，与旧版 `dev.plume.growquiz` 不同，不能覆盖旧包。

> **换版须知**：本产品已切换独立包名 `com.tvquizlock.app`，旧版 `dev.plume.growquiz` 会作为另一个应用保留。首次切换后请在电视主屏幕设置中选择“电视答题锁”为默认桌面；确认新版本运行正常后，再自行决定是否卸载旧版。卸载旧版会删除旧版本地设置与学习记录。

**方式二：自行构建**

```sh
git clone -b commercial-dev --single-branch https://github.com/cxy12193890/GrowQuizLauncher-CN.git
cd GrowQuizLauncher-CN
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk（测试构建）
```

需要 JDK 17+ 与 Android SDK（`compileSdk 36`）。正式 Release 构建必须通过本地 `keystore.properties` 或 GitHub Actions Secrets 提供固定签名密钥；未提供时 Release APK 不签名，Debug APK 仅用于测试。签名配置见 [docs/RELEASE-SIGNING.md](docs/RELEASE-SIGNING.md)。

### 2. 安装到电视

```sh
# 电视开启开发者选项与网络调试后
adb connect 192.168.1.20:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以用 U 盘 + 文件管理器、或电视上的 Downloader 类应用侧载安装。各品牌电视开启 ADB 的具体路径差异很大，完整的品牌速查表和 AI 辅助安装方法见下文[附录：把 APK 装进电视的完整指南](#附录把-apk-装进电视的完整指南)。

> **TCL / 雷鸟（FFalcon）注意**：这类固件在系统安装器里加了一道签名白名单，`adb install` 会直接报 `INSTALL_FAILED_VERIFICATION_FAILURE`。手工绕过的方法见[TCL / 雷鸟的签名白名单拦截](#tcl--雷鸟的签名白名单拦截)；用下面的安装脚本则不需要管，脚本会自动识别并处理。

### 3. 设为默认桌面

打开 **设置 → 应用 → 默认应用 → 主屏幕**，选择「电视答题锁」。

> **找不到这个设置？** 很多电视没有「默认应用」这一步：有的系统会在按主屏幕键时弹出选择框，有的压根不提供切换入口。找不到时**不用纠结，按软件内指引配置即可**——首次启动桌面会逐步引导（选默认桌面、开「主屏幕键」无障碍服务等），照着走完就能正常接管，即使厂商系统不提供手动切换入口。

安装脚本 `tools/growquiz-install.sh` 把整条部署链路串了起来：连接并等待电视上的授权 → 安装（含 TCL 签名白名单的自动绕过）→ 从电视读回版本号核对 → 授予 `WRITE_SECURE_SETTINGS` → 拉起桌面。

```sh
sh tools/growquiz-install.sh TVQuizLock-v1.13.0.apk 192.168.1.20:5555

# adb 不在 PATH 时指定路径
ADB="/d/SDK/platform-tools/adb.exe" sh tools/growquiz-install.sh TVQuizLock-v1.13.0.apk 192.168.1.20

# 省略参数则用 app/build/outputs/apk/debug/app-debug.apk 与当前已连接的唯一设备
sh tools/growquiz-install.sh
```

脚本不会禁用原桌面，出问题随时切回去。TCL / 雷鸟设备也走同一条命令，无需额外步骤。

### 4. 父母设置

所有设置都通过手机上的管理控制台完成：电视屏幕会显示形如 `http://10.0.2.15:8081` 的地址。让手机连同一个 Wi-Fi，在浏览器打开即可（首次进入需设置至少 6 位管理密码）。控制台分为**总览、设置、题库、报告**四个底部分页：

- **总览**：查看运行状态与今日概览（答题数、正确率、看电视时长），一键立即出题；宝贝被强制休息时出现警告卡，可一键解除；运行状态下方有一行**「切走弹回」自检**，直接告诉你它是正常、已关闭、缺少权限还是还没拦截过、已拦住几次；
- **设置**：修改年龄、答题间隔、思考时间、抽题分类，开关定时答题/语音朗读/开机答题/连错强制休息/切走后自动弹回；修改密码与语音朗读测试收在「工具与账号」；
- **报告**：查看宝贝学习统计（当前等级、各时段答题与正确率、知识点掌握分布、高频错题、看电视时长），与独立页 `/stats` 内容一致；
- **题库**：按年龄、分类、状态筛选题目，勾选后批量禁用/启用；「一键开关全部题目」默认折叠防误触；编辑题目在底部弹层完成；批量导入入口附 AI 出题教程和提示词模板，上传 AI 生成的 JSON 题库文件（可追加或替换），逐题校验并报告错误位置，重复题自动跳过；
- 查看每道题的答对次数——同一道题答对满 5 次会自动禁用，已掌握的题不再反复出现。

> 管理台只在局域网内可达，随桌面进程运行，不上传任何数据。

### 5.（可选）开启强锁定

普通默认桌面模式下，孩子仍可能通过系统设置或语音搜索切走应用。需要更强的约束时，配置 Device Owner：

```sh
adb shell dpm set-device-owner com.tvquizlock.app/dev.plume.quiz.QuizDeviceAdminReceiver
```

配置后答题期间启用 Lock Task，返回/主页键无法脱离。**注意**：Device Owner 不是 root，也不等于刷机；部分电视要求设备未登录账号、且没有其他设备所有者。移除方式取决于厂商系统，必要时需通过系统管理入口或恢复出厂设置处理，**请先备份数据并在可折腾的设备上试**。

### 6.（推荐）屏蔽遥控器的一键直达键

不少遥控器带 Netflix、YouTube 之类的专用键：按下后由系统直接启动对应 App，**绕过桌面**——隐藏应用、布局锁、答题拦截都管不到它，孩子一按就走。

本应用可以拦截这类按键：接管主屏幕键的无障碍服务会**先于所有应用**看到按键，把按键设为「无操作」即被吞掉：

1. 确保「主屏幕键」功能已开启（第 3 步中按提示在系统无障碍设置里开启「电视答题锁：主屏幕键」服务）；
2. 进入「桌面设置 → 主屏幕键 & 遥控器 → 遥控器按键」→「添加按键」，按下遥控器上那个一键直达键；
3. 把「按下」（必要时连「长按」）设为「无操作」即可。

说明与边界：

- 返回、OK、方向、音量、电源、主屏幕键不可改也不可屏蔽，防止误把自己锁死；
- 个别按键若在该页面按下后没有反应，说明它没有经过 Android 按键系统（如红外直接控制电视本体），此类按键无法拦截，建议停用对应 App 或换一个不带专用键的遥控器；
- 要恢复按键原功能，同一页面选「移除此按键」；
- **「添加按键」按下没反应、或之前设好的按键突然不生效**：说明无障碍服务没有真正跑起来（覆盖安装后系统会把它判为「已崩溃」且不再自动绑定，TCL 固件尤其明显）。v1.13.1 起应用会在启动后自查并重新启用一次；旧版本请到系统「无障碍」里把「电视答题锁：主屏幕键」关掉再打开一次。
- **完全不依赖无障碍的兜底**：答题页一旦被切到别的 App，会立刻（最迟一秒内）自动切回，这条路径只需要「显示在其他应用上层」权限，与无障碍无关。

## 附录：把 APK 装进电视的完整指南

不同品牌电视（和盒子）把 ADB 开关藏的位置差异很大。这一节汇总常见的开启方法与安装方式，找不到自己品牌时先用「通用法」。

### 三种安装方式怎么选

| 方式 | 适用场景 | 前提条件 |
|---|---|---|
| **U 盘安装** | 最简单，不依赖电脑和网络配置 | 电视未屏蔽 APK 安装；一个 FAT32/exFAT 格式的 U 盘 |
| **无线 ADB** | 电视和电脑在同一局域网，批量装/反复调试 | 电视开启 ADB 调试（网络调试） |
| **有线 ADB** | 无线被阉割的机型（如部分小米电视只开了 USB ADB） | USB 双公头线（小米电视用黑色 USB 口），或盒子用 OTG |

### 准备工作（ADB 方式通用）

1. 电脑下载官方 [SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) 并解压，里面有 `adb` 命令；
2. 电视连上 Wi-Fi/网线，在「设置 → 网络 → 关于/网络信息」里记下 IP 地址；
3. 确保电脑与电视在**同一局域网**（访客网络通常隔离设备，连不上）；
4. 首次连接时电视屏幕会弹「允许 USB 调试吗？」，勾选「始终允许」并确认。

### 国内电视品牌开启 ADB 速查

**通用法（先试这个）**：设置 → 关于本机 → 连续点击「版本号/产品型号/构建号」7 次 → 提示已进入开发者模式 → 返回设置 → 开发者选项 → 打开「USB 调试 / ADB 调试」，有「网络调试」的一并打开。

| 品牌 | 开启方法 |
|---|---|
| **小米 / 红米** | 设置 → 账号与安全 → 打开「ADB 调试」；新系统路径：设置 → 我的设备 → 连点版本号 ×7 → 开发者选项。注意小米多数机型默认只开 USB ADB（黑色 USB 口有线连），网络 ADB 需新系统或先有线执行 `adb tcpip 5555` |
| **华为 / 荣耀智慧屏** | 设置 → 关于本机 → 连点版本号 ×7 → 返回 → 系统和更新 → 开发者选项 → 同时打开「USB 调试」和「ADB 调试」，**重启一次生效** |
| **海信 / Vidda** | 通用法；或「我的应用 → VIDAA 助手 → 设置 → 电视调试授权」；老机型：设置 → 声音 → 音量平衡 → 遥控器输 `0532`（部分机型 `1969`）进工厂模式开 ADB。注意：VIDAA 系统（非安卓定制）多数不开放 ADB，只能 U 盘安装 |
| **TCL / 雷鸟** | 通用法可直接开；或：设置 → 系统 → 本机信息 → 遥控器依次按「上、下、左、右」弹出 ADB 开关；带数字键遥控器的老机型：信源 → 模拟接收 → 菜单 → 显示 → 专业设定 → 光标移到「对比度」→ 快输 `1950` 进工厂菜单 → Other → ADB 选项。**注意**：部分固件对侧载 APK 有签名白名单，`adb install` 会报 `INSTALL_FAILED_VERIFICATION_FAILURE`，见[对应章节](#tcl--雷鸟的签名白名单拦截) |
| **创维 / 酷开** | 设置 → 本机信息，遥控器缓慢输入「上上下下左右左右」→ 工厂菜单（部分机型密码 `123456`）→ 高级设置 → ADB 开关 |
| **康佳** | 按菜单键 → 输数字 `2008` → 工厂菜单 → 开 ADB/远程调试；或用通用法 |
| **海尔** | 信源界面按「信源键 + 左左上右」（部分机型为左左右右）→ 隐藏菜单 → 开 ADB；新机型也可用通用法 |
| **长虹** | 通用法：设置 → 关于电视 → 连点版本号 ×7 → 开发者选项 → USB 调试 |
| **乐视** | 按「信号源」键 → 输 `2580` 进工程页面 → 其他选项 → 拉到底开「ADB 调试」→ 重启电视 |
| **微鲸** | 设置 → 安全 → 直接开启 ADB 调试 |
| **PPTV** | 设置 → 联系我们 → 遥控器按「上右下左」→ 隐藏菜单开 ADB |
| **三星 / LG** | Tizen / webOS 系统，**不是安卓，不支持 ADB**，也无法安装安卓 APK |

> 工厂模式/工程菜单属于维修入口，除 ADB 开关外不要改动其他参数，误改可能导致系统异常。

### 有线 ADB（USB 双公头线）

部分机型（典型如小米电视）只开放 USB ADB 而不开放网络 ADB：

1. 用 USB 双公头线连接电脑与电视的调试 USB 口（小米电视是黑色 USB 口，蓝色 3.0 口不行）；
2. 电脑上执行 `adb devices`，电视上确认授权弹窗；
3. 如需之后用无线调试，有线状态下执行一次 `adb tcpip 5555`，拔掉线后即可 `adb connect 电视IP:5555`（重启电视后失效，需重来）。

### Android 11+ 的「无线调试」配对流程

新系统（Chromecast with Google TV、部分 Android 11+ 电视）不再直接开放 5555 端口，改为配对码方式：

```sh
# 电视上：开发者选项 → 无线调试 → 使用配对码配对设备（保持此页面开着）
adb pair 192.168.1.20:配对端口     # 输入屏幕上显示的 6 位配对码
adb connect 192.168.1.20:调试端口  # 注意调试端口与配对端口不同，在无线调试首页查看
adb install -r TVQuizLock-vX.Y.Z.apk
```

配对端口和调试端口**每次重启电视都会变化**，掉线后需重新配对。

### U 盘安装（详细步骤）

不需要电脑、不依赖网络配置，是三种方式里门槛最低的。完整走一遍：

#### 第 1 步：准备 U 盘和 APK

- 用 **8–32G 的普通 U 盘**，格式化为 **FAT32**（exFAT 新电视认、老电视多数不认，拿不准就 FAT32；NTFS 最容易读不出来）。移动硬盘别用，电视 USB 口供电弱，容易识别失败；
- 从 [GitHub Releases](https://github.com/cxy12193890/GrowQuizLauncher-CN/releases) 下载对应版本 APK，**核对文件大小**与发布页一致（下载不完整是最常见的「解析包错误」原因）；
- APK 放 **U 盘根目录**，不要套多层文件夹；文件名改成英文或数字（如 `TVQuizLock.apk`），个别电视解析中文文件名会报错；
- 确认电视系统为 **Android 8.0（API 26）及以上**：设置 → 本机信息里看「系统/软件版本」。本应用不兼容更老的系统。

#### 第 2 步：打开电视的安装权限

- 通用路径：**设置 → 安全与限制（或 安全与隐私）→ 允许安装未知来源应用**；
- 新系统多为**按应用授权**：总开关之外，还要进列表单独给「文件管理 / 媒体中心」开权限，否则 APK 能看到、安装按钮却是灰的；
- 找不到开关时：设置 → 关于本机 → 连点版本号 7 次调出开发者选项，部分机型把开关藏在这里；
- 海信 / Vidda：先开**商场模式**（设置 → 更多设置 → 通用）才放行外部安装包。

#### 第 3 步：从正确的入口打开 U 盘

把 U 盘插到电视**侧边 USB 口**（后置口兼容性略差），从这些入口打开：

- 通用：自带的「媒体中心 / 高清播放器 / 文件管理」；
- **TCL / 雷鸟**：全部应用 → **电视卫士 → 应用管理 → 极速安装**，从这里读 U 盘 APK；
- 创维 / 酷开：找不到入口时在「帮助」页调出 U 盘安装功能。

#### 第 4 步：安装并确认

1. 在文件列表里点 APK 文件；
2. 弹出安全提醒时选「**始终允许来自此来源**」（只点「允许」下次还要再确认）；
3. 等进度条走完，到「设置 → 应用」或全部应用里确认已安装。TV 应用不一定出现在手机式桌面图标里，装完在设置里能看到即成功。

#### U 盘安装常见报错

| 现象 | 原因与处理 |
|---|---|
| **解析包错误** | APK 下载不完整（重新下载并核对大小）；中文文件名（改成英文）；电视系统低于 Android 8.0（本应用不支持） |
| **安装按钮灰色点不了** | 文件管理器没有拿到「未知来源」授权：回到安全设置，单独给文件管理/媒体中心开权限，重启电视再试 |
| **提示「禁止安装该软件包」** | 厂商策略拦截（本应用声明了桌面入口，部分品牌对第三方桌面拦得最严）。U 盘方式无解，改用 ADB 方式安装 |
| **U 盘识别不到 / 列表为空** | 换 FAT32 格式；换 U 盘（别用移动硬盘）；换侧边 USB 口 |
| **U 盘打开了但看不到 APK 文件** | 电视屏蔽了 APK 后缀识别：先把后缀改成 `.apk1` 或压缩包骗过限制、在电视上装第三方文件管理器（如小白文件管理器）再改回安装；也可以先装当贝市场，再从市场里装文件管理器 |
| **装完找不到图标** | TV 应用可能不在手机式应用列表里，到「设置 → 应用」里确认已安装 |

### 让 AI 助手帮你装（WorkBuddy / 豆包）

**WorkBuddy（可直接动手）**：WorkBuddy 运行在你的电脑上、能直接执行命令。把 APK 路径和电视 IP 给它即可一句话完成，例如：

> 「帮我把 `C:\Users\me\Downloads\TVQuizLock-v1.8.0.apk` 通过无线 ADB 装到 192.168.1.20 这台电视上，装完把安装结果告诉我。」

它会自动执行 `adb connect` → `adb install -r`，并根据输出判断是否成功；连接被拒、签名冲突、设备离线等报错也会直接给出排查建议。如果没装 adb，可以先让它「帮我下载解压 platform-tools 并装好 adb」。

**豆包（帮你出方案）**：豆包不能操作你的电脑，但可以当随身顾问：

> 「我家是海信 LED55 电视，想把一个 APK 装进去，教我开启 ADB 并用电脑安装，每一步要具体点哪里。」
> 「我执行 adb connect 192.168.1.20:5555 提示 connection refused，可能是什么原因？逐一排查。」

把报错原文贴给它，让它给下一步命令，你在电脑上照做即可——这相当于"豆包出脑、你出手"；而 WorkBuddy 是"出脑又出手"。

### TCL / 雷鸟的签名白名单拦截

部分 TCL 固件（实测机型 `tcl_mt5879_cn`，Android 11）在系统安装器内部加了一道签名校验：APK 的签名必须落在该机型的白名单里，否则拒绝安装。表现是安装直接失败：

```sh
adb install -r TVQuizLock.apk
# Performing Streamed Install
# adb: failed to install ...: Failure [INSTALL_FAILED_VERIFICATION_FAILURE]
```

`adb logcat` 能看到拒绝者是谁：

```
verifier: fetch signature info from: com.tcl.cyberui
verifier: signature does not match for tcl com.tvquizlock.app, will not be installed!
```

**以下办法都无效**（实机验证过）：`settings put global verifier_verify_adb_installs 0`、`settings put global package_verifier_enable 0`、停用 `com.tcl.guard`（电视卫士）。校验发生在 `com.android.packageinstaller` 内部、早于 AOSP 的 verifier，全局开关根本够不到它。

**有效办法**：临时停用系统安装器，装完立刻恢复。

```sh
adb shell pm disable-user --user 0 com.android.packageinstaller
adb install -r TVQuizLock.apk
adb shell pm enable com.android.packageinstaller     # 必须执行
```

> `pm enable` 那一步不能省：安装器停用期间电视装不了任何应用，包括它自己的安装界面。如果忘了恢复，用同一条命令补上即可。

`tools/growquiz-install.sh` 已内置这套流程——只在真被拦下时才走这条路，并用 `trap` 保证按 Ctrl-C、报错、终端关闭时都会把安装器恢复回去。TCL 设备用脚本部署时不需要手工敲上面三行。

### 装一个中文语音引擎

电视出厂不带语音引擎时，题目能显示但不会朗读。装一个系统级 TTS 引擎即可，无需改应用：

- **推荐 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)**（Apache-2.0，离线神经网络合成）。官方提供现成的 TTS Engine APK，内含中文 Piper 模型，按电视 CPU 架构选 `arm64-v8a` 或 `armeabi-v7a` 版本，下载页见 <https://k2-fsa.github.io/sherpa/onnx/tts/apk-engine.html>。装上后在电视「设置 → 无障碍 → 文字转语音」里选它。
- eSpeak（体积小、完全离线）也能读出中文，但音色机械，只适合临时用。

装完后核对两件事，任何一项不对都会退回无声：

```sh
adb shell settings get secure tts_default_synth    # 应显示引擎包名，不能是 null
adb shell cmd package query-services -a android.intent.action.TTS_SERVICE   # 应列出该引擎
```

> 电视自带的「朗读导览 / Audio Guide」帮不上忙：它是无障碍服务，合成能力走厂商私有接口，不向第三方应用开放标准的 `TTS_SERVICE`，所以不能在这里被选用。

### 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| `connection refused` | ADB 没开 / 不在同一局域网 / 连了访客 Wi-Fi 被 AP 隔离 / 电视重启后 5555 端口关闭（重新开网络调试或有线 `adb tcpip 5555`） |
| 设备显示 `unauthorized` | 电视上的授权弹窗没点「允许」，重新 connect 并留意屏幕 |
| 设备显示 `offline` | 执行 `adb kill-server` 后重新 `adb connect` |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 签名冲突（如 debug 版覆盖正式版），先 `adb uninstall 包名` 再装 |
| `INSTALL_FAILED_VERIFICATION_FAILURE` | 厂商签名白名单拦截，TCL / 雷鸟常见。见 [TCL / 雷鸟的签名白名单拦截](#tcl--雷鸟的签名白名单拦截)，或直接用 `tools/growquiz-install.sh` |
| 切到别的应用后答题页不再弹回 | Android 10 起禁止应用在后台启动界面，需「显示在其他应用上层」权限（`SYSTEM_ALERT_WINDOW`）。安装脚本会自动授予；手动装的电视执行 `adb shell appops set com.tvquizlock.app SYSTEM_ALERT_WINDOW allow` |
| 「遥控器按键 → 添加按键」按了没反应，或设好的按键失效 | 无障碍服务没有在跑。覆盖安装会杀掉进程，部分固件（TCL / 雷鸟实测）之后不再自动绑定，服务处于「已启用但已崩溃」状态。v1.13.1 起启动后会自动重新启用一次；旧版本手动开关一遍无障碍，或执行 `adb shell settings put secure enabled_accessibility_services "$(adb shell settings get secure enabled_accessibility_services \| tr -d '\r'),com.tvquizlock.app/dev.plume.HomeOverride"` |
| 装完题目不朗读，提示「本机没有可用的语音（TTS）引擎」 | 该电视系统没有预装 TTS 引擎（不少国产电视如此）。装一个离线 TTS 引擎后到系统设置里设为默认即可，做法见[装一个中文语音引擎](#装一个中文语音引擎) |
| 点击版本号没反应 | 点得不够快或次数不够，有的电视要 8–10 次 |
| 装完找不到应用图标 | TV 应用可能不在手机式应用列表里，到「设置 → 应用」里确认已安装 |

## 工作原理

| 模块 | 位置 | 职责 |
|---|---|---|
| 定时调度 | `quiz/QuizScheduler.kt` | 用 `AlarmManager.setAlarmClock()` 排定下一次触发；Android 12+ 无精确闹钟权限时降级为 `set()` |
| 开机恢复 | `quiz/BootReceiver.kt` | 监听开机广播，读取上次排定时间并重新调度；TCL 等不投递开机广播的固件由无障碍服务绑定时补上（含恢复未完成的答题/休息、接管厂商桌面） |
| 答题界面 | `quiz/QuizActivity.kt` | 全屏、遥控器优先；可配置思考期；错误答案换题，正确答案 1.3 秒后返回；连错触发全屏休息；每秒看护前台防跳过；有 Device Owner 时 `startLockTask()` |
| 答题规则 | `quiz/QuizRules.kt` | 纯 Kotlin 逻辑（思考期、休息分钟数、蒙题检测），脱离 Android 框架，便于单元测试 |
| 题库 | `app/src/main/assets/questions/age_<5-15>.json` | 33000 题，按年龄分 11 个分片，含年龄段、分类、选项、答案下标与解析；App 按需加载单个分片 |
| 题目生成 | `tools/generate_questions.py` | 确定性生成 + 校验题库（数值干扰项自动去重、答案唯一） |
| 答题记录与自定义题 | `quiz/QuestionBank.kt` | 记录每题答对次数（满 5 次自动禁用），合并家长自定义题与题目启停状态 |
| 局域网管理台 | `web/WebAdminServer.kt` | 纯 JDK `ServerSocket` 单页服务：设置、题库维护、批量导入（`/import` 独立页）、改密码、TTS 测试；SHA-256 加盐口令、24 小时会话 Cookie，无第三方依赖 |
| 自动更新 | `ApkProvider.kt` + GitHub Releases API | 每天直接检查本项目最新 Release，安装时从本项目 Release 资产下载 APK，不依赖第三方更新服务器 |
| 本地诊断 | `DiagLog.kt` + `DeviceProbe.kt` + `CrashLog.kt` + `Vendor.kt` + `quiz/PopupAudit.kt` | 诊断事件与崩溃记录仅保存在电视本机应用私有目录，不会上传设备信息、题目记录或崩溃日志；`DeviceProbe` 只检查本机无障碍和闹钟授权状态；`PopupAudit` 用「上次闹钟时间 vs 上次答题页打开时间」的比对发现被系统静默吞掉的答题弹窗（纯 JVM，有单测） |
| 语音 | `quiz/QuizVoice.kt` + `quiz/SpeechText.kt` + `quiz/TtsProbe.kt` + `quiz/TtsDiagnosis.kt` | `QuizVoice` 是全局唯一的 TTS 引擎，桌面启动即预热；`SpeechText` 把题目改写成可朗读的中文（纯 JVM，有单测）；`TtsProbe` 供管理台检测引擎可用性，并列出本机已装引擎；`TtsDiagnosis` 把「没装引擎」与「引擎启动失败」分成两种本地诊断事件（纯 JVM，有单测） |
| 桌面本体 | `dev.plume.*` | 上游 Plume 的桌面、壁纸、屏保、按键重映射等 |

```sh
python3 tools/generate_questions.py
```

脚本会重写 `app/src/main/assets/questions/` 下的 10 个年龄分片并做一致性校验。前 800 题（id `a{年龄}-0001` 至 `-0800`）与旧版逐字节一致，已有答题记录与禁用状态不受影响；之后追加 2200 题。想换成自己出的题，按同样的 JSON 结构替换即可（`age`、`category`、`question`、`options`、`answerIndex`、`explanation`）。

## 已知限制

- **强锁定依赖 Device Owner**：不配置时只是"默认桌面"，无法阻止通过系统设置切走。
- **遥控器专用键**：Netflix 等一键直达键可绕过桌面；可被本应用拦截的键请按「快速开始」第 6 步设为「无操作」，不经过 Android 按键系统的键则无法拦截。
- **精确闹钟**：Android 12+ 若未授予「闹钟和提醒」权限，触发时间可能被系统推迟数分钟（此前兼容性测试发现不少设备未授予该权限）；桌面会提示一次，管理台总览常驻显示该状态。
- **TTS**：不少国产电视出厂不带语音引擎，此时题目照常显示但不朗读；装一个离线 TTS 引擎并在系统设置里设为默认即可，其余功能不受影响。
- **Fire TV**：Fire OS 不把 Home 键交给第三方应用，首个桌面会先闪现约 5 秒；细节见[上游文档](docs/UPSTREAM-PLUME.md#fire-tv)。
- **国产电视的桌面还原**：小米 MIUI 每次开机都会把默认桌面还给自带桌面，「设为默认桌面」不能持久；TCL 开机时无视默认桌面设置，直接拉起自带桌面。开启「主屏幕键」无障碍服务后，自带桌面（含 TCL、海信、创维、乐视、腾讯极光等）一出现本应用就自动切回；开机后服务绑定时也会主动检查一次前台，把还停留在厂商桌面的电视切回来。个别固件（海信聚好看、腾讯极光盒子的部分版本）不向无障碍服务报告窗口变化，这类机型暂时无法自动切回。
- **不做家长端远程监督**：管理台只在同一局域网内可用，且仅在桌面进程存活时开启。

## 隐私

没有账号、没有广告。应用只在以下情况使用网络：每日向本项目 GitHub Releases API 检查版本；家长主动开启天气并设置位置后访问 Open-Meteo；手机与电视在同一局域网内通过 TLS 传输家长主动上传的照片或视频。继续观看海报由本机电视内容提供程序提供。管理台只在局域网监听，密码与设置保存在电视本地。

本应用已移除自动兼容性报告上传。崩溃记录、诊断事件与本机权限状态只保存在电视应用私有存储，不上传到开发者服务器。照片或视频通过管理页添加时，手机与电视在同一 Wi-Fi 内直接传输。
